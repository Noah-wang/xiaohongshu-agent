# 中文 AI 味句式与结构

**证据强度**：经验归纳。同样看密度不看单点。

## 1 句式模板

| 模板 | 例子 | 修法 |
|---|---|---|
| 不仅…而且/更… | 「不仅好用，更好看」 | 只说你真正想说的那一件 |
| 既…又… | 「既专业又亲民」 | 同上。两个都要说就拆成两句 |
| 从…到…，都… | 「从选题到成稿，全都帮你搞定」 | 换成一个具体的例子 |
| 在这个…的时代 | 「在这个信息爆炸的时代」 | 整句删。这类句子在任何文章里都成立 |
| 作为一个…，我… | 「作为一个资深跑者，我……」 | 直接说事，身份让内容自己体现 |
| 是…，也是…，更是… | 递进排比 | 保留一个 |
| 自问自答 | 「为什么？因为……」连用 | 全文最多一次 |
| 三点式排比 | 三个并列的形容词/短句，到处都是 | 改成两个或四个，打破节奏 |

## 2 结构性痕迹

**万物皆三。** 三个要点、三个理由、三个场景。真人想到几个写几个，四个就是四个，两个就是两个。检查全文：是不是所有列举都恰好三项？

**每段都有总结句。** 每个段落最后一句都在概括本段——这是机器的段落写法。真人的段落经常戛然而止，或者最后一句是个跑题的吐槽。

**段落等长。** 数一下每段字数。整齐是机器特征。该展开的展开，该一句话的就一句话。

**开头即宣告主题，结尾即复述主题。** 分形式总结——总起、分述、总结，每一层都来一遍。删掉最外层那圈。

**emoji 均匀分布。** 每段开头一个 emoji、每个分点一个 emoji，位置和数量高度规整。真人的 emoji 是情绪驱动的，会扎堆在激动的地方，平静的段落一个都没有。

## 2.5 假随意（过度矫正）

去 AI 味做过头会造出一种新指纹：**刻意的口语腔**。它比套话隐蔽，因为每个词都很"接地气"。

统一特征：**这句话在给下一段报幕，不在传递信息。**

| 形态 | 例子 |
|---|---|
| 祈使式过渡 | 先对个时间，别跑空：· 先说结论，不绕弯 · 话不多说，直接上 |
| 假江湖气 | 说人话就是 · 讲白了 · 不整虚的 · 先把话撂这儿 |
| 「A一下，别B」对仗 | 先看一眼，别急着买 · 先想清楚，别乱冲 |
| 强行省略主语的命令句 | 记住三个字 · 就干一件事 |

**判据**：把这句删掉，正文信息量有损失吗？没有就是报幕句，删。

**为什么会出现**：模型被要求"别写得像 AI"，就往"糙"的方向使劲。但人类的随意是**不均匀**的——偶尔冒一句，不是每段开头都来。密度是判据：全文出现一次没问题，两次以上就是模板。

**修法**：直接删，不要替换成另一个过渡句。想说的话紧接着说就行。

## 3 小红书特有

| 痕迹 | 说明 |
|---|---|
| 标签全是大词 | #生活 #分享 #好物 —— 没有精准词，是没做功课的信号 |
| 开头必用钩子词 | 每篇都「谁懂啊」「救命」，成了模板就失效了 |
| 分点符号统一 | 全篇 1️⃣2️⃣3️⃣ 或全篇 ✅，没有变化 |
| 没有任何缺点 | 全是优点的种草文，可信度接近零 |
| 数字全是整数 | 「省了 3 小时」「便宜了 50 块」——真实数据很少这么圆 |

## 4 读出来测试

默读全文。三种情况要重写：

1. **不像话**——语法对但没人这么说
2. **喘不过气**——长句套长句，中间没有停顿
3. **像念稿**——节奏太整齐，没有真人说话的磕绊

## 5 修法优先级

从深到浅，不要跳级：

```
结构（万物皆三、段落等长、分形总结）
   ↓
句式（排比、不仅而且、自问自答）
   ↓
词汇（套话、黑话、空心形容词）
```

先改词汇是无效的——结构不动，换掉几个词还是一眼 AI。
