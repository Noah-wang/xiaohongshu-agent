# 干货帖

## 核心原则

**信息密度决定收藏率。** 干货帖的目标不是点赞，是收藏——读者觉得"以后用得上"。

三条硬规则：

1. **标题必须承诺一个具体收益。** 「3 个方法」「一篇讲清」「踩了 5 个坑」——量化的承诺比模糊的「分享」更容易被点开。
2. **每一条都要能立刻用。** 「要注意休息」是废话，「跑量周增幅不超过 10%」是干货。
3. **不要凑数。** 3 条扎实的比 8 条注水的强。宁可短。

## 结构

```
标题——承诺具体收益
    ↓
开头 1-2 行——说明这是给谁的 / 什么情况下用
    ↓
正文——分点，每点：小标题 + 一句解释 + 一个具体例子或数字
    ↓
结尾——一句话总结，或者留一个进阶钩子
```

## 排版

小红书不渲染 markdown，靠 emoji 和空行做视觉层次：

- 用 1️⃣2️⃣3️⃣ 或 ✅ 做分点，不要用 `-` 或 `1.`
- 每点之间空一行，手机上才不糊
- 关键数字/结论可以单独成行
- 全文控制在手机 3-4 屏内

## 语气

- 可以直给，不用铺垫太多
- 「我踩过这个坑」比「据说」可信
- 承认不确定：「这个我还没验证过」不减分，反而加分

## 话题标签

3-6 个，偏精准。干货帖靠搜索长尾流量，标签要贴近读者会搜的词。

## 反面示例

> ❌ 「分享一些跑步的小技巧～希望对大家有帮助！记得多喝水，注意拉伸，循序渐进哦～」

全是正确的废话，读者拿不走任何东西。

> ✅ 「跑量周增幅别超 10%，这是我拉伤两次换来的。
>
> 具体说：这周 40 公里，下周最多 44。想冲量就在第 4 周减到 30，给身体一个吸收期。
>
> 我第一次受伤就是 35 直接干到 50。」
