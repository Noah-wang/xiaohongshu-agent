# 配图视觉规范

## 为什么要锁死风格

单张图好看没用。**账号主页是九宫格**，读者第一眼看的是整体。如果每篇配图风格不同，主页会显得杂乱，像搬运号。

所以下面这些参数是**固定的**，模型只负责填「画什么」，不要自己改「怎么画」。

## 固定参数

| 维度 | 规定 |
|---|---|
| 比例 | 竖构图 2:3（1024×1536）。小红书首图理论最佳是 3:4，但 gpt-image-2 只有固定几档尺寸，竖版就这一档 |
| 色调 | 低饱和、暖调；主色偏米白/浅木色/暖灰 |
| 光线 | 自然柔光，避免硬阴影和强对比 |
| 构图 | 中心留白，主体占画面 60% 左右，不要满构图 |
| 质感 | 真实摄影感，浅景深；**不要**插画、3D 渲染、赛博朋克 |
| 文字 | **画面内不要出现任何文字**（AI 生成的中文字几乎必然是乱码） |
| 人物 | 尽量不出现清晰正面人脸；需要人时用背影、手部特写或侧影 |

## prompt 组装方式

最终 prompt = **主体描述**（你根据正文写）+ **固定后缀**（原样附上）

固定后缀：

```
vertical composition, soft natural daylight, low saturation warm tones,
beige and light wood palette, shallow depth of field, realistic photography,
centered subject with generous negative space, no text, no watermark,
no visible faces, clean minimal aesthetic
```

## 主体怎么写

从正文里抽**一个具体的物**或**一个场景瞬间**，不要抽抽象概念。

- ✅ 「一块运动手表放在木桌上，旁边一杯温水，晨光斜照」
- ❌ 「科技与运动的结合」（抽象概念画不出来，模型会乱编）

产品类帖子建议画**使用场景**而不是产品本身——你的产品是软件，画界面截图不如画「一个人跑完步坐在台阶上看手表」。

## 检查清单

出图后自己看一眼：

- [ ] 是竖图吗
- [ ] 画面里有没有混进文字/水印
- [ ] 色调跟你之前几篇像不像
- [ ] 有没有出现诡异的人脸或多余的手指
