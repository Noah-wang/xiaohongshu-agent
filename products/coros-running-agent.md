## 面向谁

- 用 COROS 手表、认真跑马拉松/半马的严肃跑者，不只是刷步数
- 想要定制化 AI 教练，但不愿把个人训练数据上传到未知云端
- 有基本自托管能力（或愿意折腾 Python/服务器）的技术型跑者
- 对通用聊天机器人不满意，希望 AI 记住自己的配速、伤病、目标和主观体感

## 解决的痛点

- COROS App 只告诉你「数据是什么」，不告诉你「数据意味着什么、下一步怎么练」
- 网上跑步知识和书太多，但和自己的训练记录完全脱节，很难落地
- 请真人教练贵；通用 AI 不了解你，每次都要重复背景
- 训练体感、目标、伤病这些非数据信息以前只能存在脑子里，AI 参考不到
- 隐私顾虑：不想把心率、路线、伤病细节交给第三方 SaaS

## Before / After

**Before**：跑完看一眼手表，配速 5'20、心率 148、负荷「有氧 3.0」。但心里没底——最近三周是不是练太狠？下次长距离该按什么强度？翻书刷视频问通用 AI，没一个结合自己的实际情况。

**After**：直接在 Discord/Web 里问「我最近三周训练负荷是不是太高」。它调取 COROS 近期活动、比对长期记忆里的体感记录、检索导入的训练书和视频字幕，给出结构化复盘和下周期建议。你说过的「膝盖有点紧」「目标是 11 月上马」「最近睡眠一般」都会进入它的考量。

## 三个真实使用场景

1. **晨跑后一句话复盘** — 长距离跑完在 Discord 发「今天这次训练怎么样」，它读刚同步的 COROS 数据，结合负荷、恢复状态、目标日期给出评价和调整方向。

2. **把喜欢的 UP 主变成知识库** — `!knowledge-source 空间链接 training`，定时抓取该 UP 主新视频字幕入库建索引。之后问「现在这个跑量阶段适合练哪种间歇」，它会引用这些内容并附字幕出处。

3. **长期档案沉淀** — 告诉它「左膝外侧有点紧」「下周出差一周」「全马目标破 3」，写进长期记忆，之后每次生成报告都纳入推理。还会自动推送每日/每周训练报告和睡眠 HRV 恢复报告。

## 已知短板（发「踩坑」「劝退」类帖子的素材）

- **有自托管门槛**：需要 Python 3.13+、uv、Node.js 18+，还要自备 LLM API key，不是下载即用
- **单人单数据绑定**：没有多用户和登录，一份部署只服务一个人，家人要用得分开部署
- **配置暗坑**：连接 COROS 时 mcp-remote 必须锁版本号，否则卡在「等待授权」永不返回；B 站字幕同步需登录态且有限流，触发风控只能等
- **依赖模型能力**：主 Agent 需要支持工具调用的 LLM，弱模型走不完训练报告工作流
- **知识库规模有限**：没用向量数据库，适合个人几百篇文档，海量导入后检索性能会退化
- **不是真人教练**：伤病相关只能做风险提示，不能替代专业医疗建议
